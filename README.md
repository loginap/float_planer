# Mood-Based Task Planner Bot

Telegram-бот для "плавающего" планирования задач на основе вашего текущего настроения.

> **Идея:** Классические планировщики терпят неудачу, потому что не учитывают наше изменчивое внутреннее состояние. Этот бот подбирает задачи, которые подходят вам прямо сейчас.

## 🚀 Быстрый старт

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ваш-логин/MoodBasedPlannerBot.git
    ```
2.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
3.  Настройте бота:
    *   Создайте бота через [@BotFather](https://t.me/botfather) и получите токен.
    *   Создайте файл `.env` по образцу `.env.example` и вставьте туда ваш токен.
4.  Запустите бота:
    ```bash
    python src/bot.py
    ```

## 📖 Документация и описание функционала

Полное описание команд, тегов и настроений доступно в [документации на русском](docs/BOT_DESCRIPTION_RU.md).

**Основные команды:**
*   `/start`, `/help` — начало работы и справка.
*   `/add_note` — пошаговое создание задачи с тегами, приоритетом и дедлайном.
*   `/recommend` — получить рекомендации задач под ваше настроение.
*   `/plan` — построить оптимальный план на указанное время.

## 🛠 Технологии

*   **Язык:** Python 3.10+
*   **Библиотеки:** python-telegram-bot, python-dotenv, sqlite3 (или другая БД)
*   **Платформа:** Telegram Bot API
